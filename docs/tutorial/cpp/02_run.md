# Run TEPL rewrites from C++

C++ code generation is currently unavailable. The previous generated C++ API
and its host-function examples have been removed from this tutorial.

TEPL rules use builtins and descriptor constructors; `$` host calls and `fn`
parameters are unsupported. See [attributes and conditions](../../advanced/attributes_and_conditions.md).

Use the [Rust tutorial](../rust/02_run.md) for generated application integration,
or the [greedy rewrite engine](../../advanced/greedy_rewriting.md) to execute
compiled rules through the CLI.
