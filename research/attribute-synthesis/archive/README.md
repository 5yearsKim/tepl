# Archived attribute-synthesis research

These notes preserve earlier approaches and restricted fragments. They are not
current compiler documentation. Start with the
[collection index](../README.md) for the primary paper, proofs, and scripts, or
[implementation design](../../../design/attribute-synthesis.md) for active code.

| Material | Original purpose |
| --- | --- |
| `ordered_contractions.md`, `check_ordered_contractions.py` | Original ordered contraction argument and exhaustive oracle |
| `finite_rank_restrictions.md`, `math_theorem.md` | Finite-rank restrictions and theorem proposals |
| `sparse_counterexamples.md`, `early_verification.md` | Bounded early rejection and sparse witnesses |
| `ir_extensions.md` | Earlier representation proposal |
| `convolution_attribute_synthesis_proof.md`, `validate_convolution_completeness.py` | Restricted convolution construction and exact small oracle |
| `check_auto_solution_space.py` | Earlier attribute-solution-space enumeration |
| `check_supplied_broadcast_axis_synthesis.py` | Earlier supplied-extent broadcast experiment |

Historical host APIs and implementation references remain evidence of those
approaches, not instructions for the present compiler. The standalone scripts
can be run directly with Python 3; exhaustive settings may be expensive.
