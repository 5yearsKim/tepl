# Historical semantic codegen fixtures

The sibling `semantic*.tepl`, Rust, and C++ fixtures describe the previous
runtime-search interface. `tensor.tepl` preserves their dialect for reference.
They use retired element-semantic syntax and cannot be regenerated by the
current compiler.

The codegen integration scripts run ordinary supported fixtures. These legacy
semantic fixtures are excluded explicitly until generators support the new
symbolic attribute constructors. Existing generator implementations and runtime
wire interfaces are preserved. The native compatibility test is
`//tests:legacy_semantic_runtime_test`.
